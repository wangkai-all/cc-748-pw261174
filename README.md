# 工期风险分析台（Schedule Risk Workbench）

面向施工工序网络的工期风险分析项目：把**虚构工序网络、持续时间样本与共同风险源**
接入一个零依赖（Python 标准库 + 原生 HTML/JS/SVG）的网页服务，模拟项目完工时间、
估计每道工序的关键程度，并在**同一组随机场景（共同随机数，CRN）**下比较赶工方案的
准时概率与成本前沿。

## 为什么不是独立抽样

施工工序耗时受共同天气和材料延迟影响。本项目的所有随机性都只从**共同风险源**
（risk factor）注入：

- 每个场景先对每个风险源抽取一次潜在冲击（normal / lognormal / bernoulli，
  风险源之间可用高斯 copula 给定相关矩阵）；
- 工序持续时间 = 名义工期 + Σ(加载系数 × 风险源实现值) + 工序专属残差；
- 代码中不存在“给各工序添加彼此独立噪声”的入口，独立抽样无法冒充共同冲击。

因此同一道降雨会同时拖延所有户外工序，独立抽样低估整体拖期的问题在结构上被排除。

## 赶工与共同随机数（CRN）

- 赶工只能把工序压向数据支持的 `min_duration`，超出区间的请求返回
  `crash_beyond_limit`，服务端不会静默接受。
- 场景对 `(seed, n_scenarios)` 只生成一次并缓存；任何赶工方案都只是对**同一批**
  基础持续时间做压缩后重跑 CPM，不重新抽样——方案差异不会被采样噪声冒充。
- 成本前沿逐增量比较每道可压缩工序在相同场景下的期望工期改善，按“单位成本节省天数”
  贪心推进，并给出每个前沿点的准时概率、P5/P50/P95 与预算约束校验。

## 三类非法网络的解释

| 数据集 | 问题 | 服务端错误码 |
|---|---|---|
| `data/bad_cycle.json` | 前置关系成环，无法拓扑排序，CPM 无定义 | `cyclic_dependency`（附环上工序） |
| `data/bad_resource.json` | 名义最早开始计划即超出资源容量 | `resource_capacity_conflict`（附资源、时段、需求量与占用工序） |
| `data/bad_deadline.json` | 截止期短于全压缩后的最短可达工期 | `unreachable_deadline`（附极限工期） |

## 计算中改方案：旧任务结果不得覆盖新页面

每个方案（数据集、种子、场景数、截止期、预算、赶工分配）经 SHA-256 生成
**方案签名**。前端启动新计算时：

1. 停止旧轮询器并请求服务端取消旧任务（代次 token 防止快速连点时轮询泄漏）；
2. 新任务完成后只在其签名等于页面最新签名时才写入结果；
3. 旧任务即使晚完成，也因签名不匹配被丢弃，无法覆盖新页面。

服务端任务在守护线程中运行，支持取消、进度查询与状态轮询。

## 内置数据集

- `tiny_analytic.json` — **解析可验小网络**：两道平行正态工序 A=10+2Zₐ、
  B=12+1.5Z_b 汇入里程碑，闭式解与蒙特卡洛结果互验
  （关键度 Φ(-0.8)≈0.2119、准时概率、E[max]≈12.3005）。
- `confluence.json` — **多风险合流样例**：8 道工序、4 个共同风险源
  （降雨/低温以 0.6 相关、伯努利钢材中断、对数正态混凝土波动）、2 类容量受限资源。
- 三个 `bad_*.json` 非法样例（见上表）。

## 运行

```bash
python3 run.py                 # 默认 http://127.0.0.1:8000
python3 run.py --port 8011
```

浏览器打开后：选择数据集 → 设置种子/场景数/截止期/预算 → **运行模拟** 或
**计算成本前沿**；点击网络图节点查看迟延来源、用滑块分配赶工预算（仅允许数据支持的
区间）并重新模拟；底部可导出**场景级明细**（CSV/JSON）与成本前沿 CSV。

## 测试（固定种子复核模拟、关键路径与预算约束）

```bash
python3 -m unittest discover -s tests -v
```

36 个测试覆盖：

- 解析闭式解 vs 蒙特卡洛（关键度、准时概率、期望完工时间）；
- 固定种子逐位复现、共同风险源相关性、伯努利冲击频率、CPM 关键路径成员；
- CRN 一致性（不同方案消费完全相同的场景）、赶工区间约束、前沿单调性与预算上限；
- 循环依赖 / 资源容量 / 不可达截止期三类校验；
- 后台任务签名、取消、快速改方案的防覆盖语义；
- 完整 HTTP API 生命周期与场景级导出。

## 目录结构

```
app/
  models.py      数据模型与数据集校验（含相关矩阵 PSD 检查）
  rng.py         种子随机流、正态 CDF/PDF、Cholesky（copula）
  risk.py        共同风险源抽样、持续时间生成、赶工变换与成本
  schedule.py    CPM 正反向计算、关键路径、资源容量、截止期可达性
  simulation.py  场景生成、蒙特卡洛、关键度/关键性指数、迟延归因、直方图
  crashing.py    赶工请求校验、成本-工期-准时概率前沿（CRN 贪心）
  jobs.py        后台任务、方案签名、取消与防覆盖
  layout.py      确定性分层网络布局
  exports.py     场景级 CSV / JSON 与前沿 CSV 导出
  server.py      纯标准库 HTTP 服务（REST + 静态页面）
data/            内置数据集（含解析可验与三类非法样例）
web/             单页前端（原生 JS + SVG，无构建步骤）
tests/           unittest 套件
run.py           启动入口
```

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/datasets` | 数据集目录 |
| GET | `/api/networks/{id}` | 网络定义、布局、确定性 CPM |
| GET | `/api/validate?dataset=…&deadline=…` | 结构/资源/截止期校验 |
| POST | `/api/simulate` | 启动模拟任务（202 + job_id + 签名） |
| POST | `/api/frontier` | 启动成本前沿任务 |
| GET | `/api/jobs/{id}` | 轮询状态/进度/结果（结果带签名） |
| POST | `/api/jobs/{id}/cancel` | 取消任务 |
| GET | `/api/export/{job_id}?format=csv\|json` | 场景级 / 前沿明细导出 |
